# 深港跨境拼车撮合小程序

为深港跨境通勤者（现阶段：往返香港教育大学的师生）提供**拼车局撮合**：找到上车时间相同的队伍，组队拼坐香港的士。**纯撮合**——不预约车辆、不经手车费，AA 线下进行。

> 领域词汇与决策见 `CONTEXT.md`、`docs/DESIGN.md`、`docs/adr/`；云函数契约见 `cloudfunctions/SPEC.md`。

## 目录结构

- `sgy/` — 小程序前端（微信云开发，app.js 需填云环境 ID）
- `cloudfunctions/` — 云函数：`rides`（**唯一业务函数**：拼车局 + 用户档案/信用/复核 + 校内身份 + 反馈，原 `user` 已并入，见 ADR-0012）、`routeInit`（建集合+线路种子）、`rideSweep`（状态机定时推进）
- `CONTEXT.md` / `docs/` — 领域词汇、设计快照、ADR 决策记录

## 主要功能（MVP）

- 游客可浏览；**注册（填昵称）后**才能发起 / 加入 / 提交反馈 / 登记校内身份
- 找局：返校 / 离校、上车·下车点、空位筛选；卡片显示真人小头像（蓝男·粉女）
- 发局：返校固定终点教大；离校可自定义香港下车点（ADR-0009）；**人数上限默认 4、可设 2–6**（容纳六人座车）
- 拼车局时间线：提前 1 小时全员确认 → 提前 30 分钟自由退出 → 提前 10 分钟停止加入、≥2 人成局 → 上车后 45 分钟结算进历史（深港单程最慢约 45 分钟）
- 集合协调：**无站内聊天**（2026-09-10 下线，ADR-0017）——成员按约定时间到上车点的士站集合，凭**备注**（发起人写集合点细节）与**成员列表**（签到态/性别色/✓校内绿标）互相辨认；车费线下当面 AA
- 信用与举报：爽约扣分；举报（性别不实/迟到/缺勤）≥2 人联名自动坐实或管理员复核；可标记"不与其乘车"
- 校内身份（防逃跑威慑）：自报学号（s+7 位），同车只见「✓ 校内已登记」绿标，明文仅本人/管理员（ADR-0013）
- 反馈与建议：我的 → 提交（仅注册），管理员后台查看/标记已处理
- 已完成局：查看记录、下周同一时刻再约、向队友举报
- 管理员后台：待复核举报坐实/驳回 + 反馈查看/标记 + 校内身份复核/撤销 + 代发种子局

## 部署（详见图 cloudfunctions/README.md）

1. 微信开发者工具打开本目录（`miniprogramRoot: sgy/`）
2. 开通云开发，环境 ID 填入 `sgy/app.js` 的 `env`
3. 上传 3 个云函数（`rides` / `routeInit` / `rideSweep`），跑一次 `routeInit`；**云端旧 `user` 函数删除**（已并入 rides）
4. 按 `cloudfunctions/README.md` 建索引、设集合/存储权限、把作者 openid 填进 `rides/db.js` 的 `ADMIN_OPENIDS`

## 测试注意

- 一人可同时持有多局：任意两局出发间隔 ≥1 小时；**同方向（返校×返校 / 离校×离校）需 ≥2 小时**（同向要先完成一趟往返）
- 举报规则：同一人同一局同一类只能举报一次；≥2 名不同成员联名自动坐实（性别不实 −20 并清空性别、缺勤 −20、迟到 −10），否则转管理员复核
