# ADR-0014：返校自定义上车点（与离校自定义下车点对称）

- 状态：已采纳（2026-09）
- 关联：ADR-0009（离校自定义下车点）、ADR-0003（固定线路目录）

## 背景

离校已支持在目录外自定义香港下车点（ADR-0009）。用户提出返校同样放开：返校是"深圳/香港侧上车 → 教大"，上车点也可能落在目录外的任一香港地点（如其它站/口岸、甚至顺路某处），应允许自定义。

## 决策

把"自定义"从离校下车点扩展为**双方向对称**：

- **返校**：`rides.create` 在 `routeId` 缺省、`directionId='in'` 时接受 `from` 自定义上车点（文本 ≤14 字，`to` 固定香港教育大学）。
- **离校**：不变（`to` 自定义，ADR-0009）。
- 找局筛选：返校上车点下拉增加「自定义上车点（其它香港地点）」项，选中后只显示无 `routeId` 的返校局（与离校自定义下车点筛一致）。

## 理由 / 取舍

- 对称最简单：发局/找局两端复用同一条"自定义"交互与筛选逻辑，心智一致。
- 自定义文本 ≤14 字，控制卡片/冲突对比表展示长度（与离校一致）。
- 代价：自定义点不校验是否真有"的士站"——上车集合位置由成员在局聊天室内约定（与目录点同样口径，见 CONTEXT 上车点）。若后续发现需要限制到"站/口岸"类，可再加校验或白名单。
