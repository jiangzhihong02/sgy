# 信任体系：自报 + 信用分，不引入押金与强实名

信任采用"微信手机号验证 + 可选自报性别 + 轻量信用分"，具体规则：

- 初始 100 分。
- 普通爽约 −20；签到"我到了"后放鸽子 −40；无理由乱标他人爽约（核实后）−10。
- 成功同行（双方 T+15 内签到且局顺利完成）+1，封顶 120。
- 信用 <60：暂停发起新局 7 天（仍可加入别人的局）。
- 申诉：被标者提交说明，管理员人工复核后撤销或维持扣分。

曾被否决的替代方案：押金制、强实名/证件核验、接入支付做履约担保——都超出"纯撮合"边界且抬高 MVP 门槛。性别同为轻信任设计：自报（微信不提供真实性别）用于头像框着色辨认；自报不实可被同车成员检举，管理员查实后清空性别并扣 −20。后果：恶意成本低，依赖内测期圈子自净；各项数值为可调参数，后续按数据调整。
