# MVP 走内测体验版，正式上架（类目 / 资质 / 订阅模板）作为后续门槛

一期以"体验版 + 身边真实通勤圈子"内测验证需求，不正式上架。正式上架前需解决三件事，在调研结论明确前不阻塞开发，但影响数据模型与订阅设计：

1. 拼车/顺风车/出行撮合类目对主体（个人 vs 企业）与资质的要求——本产品是免费、非交易撮合，能否以轻量类目上架待查。
2. 订阅消息公共模板的可得性——"有人加入你的局 / 满员 / 出发提醒"类提醒是否有匹配模板，通常取决于所属类目。
3. 个人信息合规——收集手机号用于验证，涉及《个人信息保护法》的告知同意。

数据模型与订阅调用处应预留开关，避免未来上架受阻时返工。

Status: accepted
