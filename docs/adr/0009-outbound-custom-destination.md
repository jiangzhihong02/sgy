# 离校允许自定义下车点（返校仍走固定目录）

一期原按 ADR-0003 只做固定线路目录、不做"任意两点"。用户反馈离校场景下，住在口岸之外香港地点的同学（如粉岭、上水）同样想拼一程的士——例如放学从教大拼到粉岭。因此开放：**离校（`directionId='out'`）发起时可选择 3 个口岸预置下车点，或填写任意香港自定义终点**；返校（`directionId='in'`）保持固定目录（终点恒为教大）。

实现上自定义局没有 `routeId`，靠文档内的 `from`/`to` 快照展示与匹配；找局页"离校 → 全部下车点"下拉把"自定义终点"作为一档聚合展示。

后果：自定义终点不保证匹配率高（自由文本、无归一到口岸），匹配主要靠时间/方向 + 同片区直觉；属可接受的 MVP 扩展。Status: accepted。
