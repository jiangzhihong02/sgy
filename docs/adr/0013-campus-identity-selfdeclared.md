# ADR-0013：校内身份 = 自报登记（非微信实名），对外只给绿标

- 状态：已采纳（2026-09）
- 关联：ADR-0001（只撮合、不经手车费）、ADR-0005（轻量信任信用分）、ADR-0010 #11（性别分级）

## 背景

用户担心拼车「逃跑/放鸽子」无保底，提出做实名。但：

- 小程序**拿不到微信实名明文**（隐私收紧后仅支付/特定认证能力下暴露，普通小程序不可得，且涉及实名信息收集合规）；
- 一期内服务对象是香港教育大学师生，是有明确身份域的小众通勤群。

## 决策

不做"实名制"，改为**自报校内身份登记**：注册用户填「学校（一期固定教大）+ 学号（s+7 位数字，格式校验）+ 真实姓名（+ 可选专业）」，存于 `users.schoolId`。

- **自报不核验**：真伪不做人工/邮箱核验（二期可按需加）；
- **对外只给绿标**：同车成员资料仅显示「✓ 校内已登记」布尔（`memberInfo.schoolVerified`），**学号/姓名明文不下发**给他人；本人可通过 `me` 看到自己的明文；
- 管理员后台可见全部明文用于复核，并可 `adminClearIdentity` 一键撤销乱填。

## 理由 / 取舍

- 自报+绿标的**威慑成本低、零合规负担**，符合内测 MVP 定位；真要"抓逃跑"还有 信用分（爽约扣分）+ Block 语义兜底，实名并非唯一保底。
- 学号明文不外发，避免被同车人社工/冒用；"只绿标"是我们对敏感字段的克制。
- 换来的代价：绿标不保证真身份（有人乱填别人学号也可能通过格式），所以定位是**威慑 + 线下好辨认**而非身份证明——二期若要更强，再加邮箱/学号核验或邀请制。
