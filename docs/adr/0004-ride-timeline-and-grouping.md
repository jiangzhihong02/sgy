# 拼车局时间线与成局规则（T−60 轮询 / T−30 自由退出 / T−10 关局）

拼车局以"上车时间 T"为中心运行：

| 时刻 | 规则 |
|---|---|
| 招募期 | 可被"找局"看到、可转发拉人；T−10 前可加入 |
| T−60 | 若成员 <4，向全员发起"是否接受当前人数出发"轮询；T−45 未回复默认视为接受 |
| T−60 ~ T−30 | 因成员进出可重复发起轮询 |
| T−30 | 自由退出 / 发起人解散的最后时点；此后退出计爽约、发起人不可解散 |
| T−10 | 停止加入；成员 ≥2 → 成局锁定；<2 → 未成局自动解散（不计爽约） |
| T | 上车点集合，成员点击"我到了"签到 |
| T+10 | 未签到且未在聊天室说明 → 同局成员可标记爽约 |

成局门槛定为 2 人，保证"两人即可成行"；T−60 轮询则是给"不足满员 4 人"的局一个提前确定的出口，避免临到点才散伙。完整判定与状态见 docs/DESIGN.md。
