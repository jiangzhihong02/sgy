# 用户隐私保护指引 · 后台填写文案（mp.weixin.qq.com）

> 用途：微信公众平台 → 设置 → 服务内容声明 → **用户隐私保护指引** → 按下列勾选并填用途说明。
> 填完必须点「发布/更新」生效，随小程序基础库 ≥2.32.3 在首次触发隐私接口前向用户展示。
> 对照代码核验（2026-09-09）：全小程序唯一隐私接口 = 聊天室发图 `wx.chooseMedia`（相册+摄像头，
> `chat.js onPickImage`）；**未使用** 位置 / 手机号 / 通讯录 / 麦克风 / 身份证 / 支付。收集的其余为用户在各表单手填字段。

## 勾选与用途说明（整句可粘贴）

| 信息类型 | 勾 | 用途说明 |
|---|---|---|
| **相册（选择图片）** | ✅ | 用户主动从相册选择 1 张图片（通常为微信群二维码、AA 收款码或集合照片），发送到自己参与的拼车局聊天室，供同车队友查看或加群。图片经压缩后以 base64 存入该局消息记录，仅局内成员可见，不自动读取相册其他内容，不用于其他用途。 |
| **摄像头（拍摄照片）** | ✅ | 允许用户现场拍摄照片发送到拼车局聊天室，用途同上。（如不想申报，可把 `chat.js` 的 `sourceType` 改为仅 `["album"]`。） |
| **昵称（用户填写的注册信息）** | ✅ | 用于拼车局内成员互相辨认；未填时系统生成随机昵称，可自行修改，不关联真实身份。 |
| **性别（用户自报）** | ✅ | 用户自愿填写，用于同车时辨认（队伍头像框着色）；不用于统计或对外共享。 |
| **校内身份信息（自定义信息：学校+学号+真实姓名+可选专业）** | ✅ | 用户自愿登记校内资料，作为队伍内诚信威慑（防逃单）。**自报不核验、非实名认证**；学号与姓名明文仅本人与开发者后台可见，同车成员只能看到「✓ 已登记」绿标。 |
| **聊天记录（文字+图片）** | ✅ | 拼车局内成员间临时沟通（约集合点、AA 结账），仅该局成员可见；局完成后再保留 48 小时后停止发言，历史仍可在「行程」查看。 |
| **反馈内容** | ✅ | 用户在「反馈与建议」提交的意见，仅开发者后台可见，用于改进产品。 |

## 保存期限/范围统一句

> 数据存储于腾讯云开发服务器（境内），仅用于本小程序拼车撮合功能；无广告、无第三方共享、无跨境传输。

## 与用户生成内容声明的口径一致

文本（聊天/昵称/备注/反馈等）已接微信 `msgSecCheck` 自动拦截违规；聊天图片**不接机器检测**（个人主体云调用不支持
`imgSecCheck`），靠仅同局成员可见 + 每人每局限 1 张 + 举报与管理员复核兜底——两处声明口径须保持一致，见
`docs/ugc-security-statement.md`。
