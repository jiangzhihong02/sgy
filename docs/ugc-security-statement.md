# 用户生成内容（UGC）场景信息安全声明

> 适用：深港跨境通勤拼车撮合小程序（以实际注册名为准）· 提审用信息安全管理说明
> 版本日期：2026-09-10（2026-09-09 版随站内聊天下线而重写，见 ADR-0017）

## 一、开发者与定位

开发者：sgy（微信个人主体，非营利、公益性质运营）。
本小程序是一个面向高校师生的**深港跨境通勤组队工具**：帮助用户找到「同一上车时间、同一集合点」的拼车伙伴，凑齐人数后自行拼坐香港的士。它**只提供线上组队撮合**——不预约车辆、不经手车费、不承担承运，费用由成员线下当面结算。全程无广告、无付费功能。

## 二、用户内容形态与可见范围

本小程序**不提供站内聊天、不提供图片上传、没有公开广场或信息流**。用户在使用过程中填写的内容仅为以下**结构化功能字段**（均为短文本，配合发起/加入/登记等动作使用）：

| 场景 | 内容形态 | 填写者 | 可见范围 |
|---|---|---|---|
| 发起拼车局 | 自定义上车/下车点（≤14 字的地点名） | 发起人 | 找局列表 / 局详情 |
| 发起拼车局 | 集合提示备注（≤50 字，如"的士站最右边柱子集合"） | 发起人 | 找局列表 / 局详情 |
| 注册资料 | 昵称（默认随机可改） | 注册用户本人 | 局内成员列表 |
| 注册资料 | 性别（自报、可选） | 注册用户本人 | 局内成员列表（用于头像框着色辨认） |
| 校内身份自报 | 学校 + 学号（s+7 位）+ 真实姓名（可选专业） | 注册用户本人 | **学号与姓名明文仅本人与管理员可见**；同车成员只见「✓ 校内已登记」绿标 |
| 反馈与建议 | 文字 | 任意注册用户 | 仅开发者后台 |

**无内容共享面说明**：以上字段均为"一局车"的结构化元数据或用户自报资料，附着于拼车局或用户档案；不存在用户发布内容供他人浏览/订阅的频道。成员间协调（集合位置、车费结算）走**到点集合见人与线下当面**，不依赖站内内容。

## 三、内容安全管理机制

1. **文本内容安全检测（微信内容安全接口）**：对用户填写的**文字**字段（自定义上车/下车点、备注、昵称、校内身份姓名、反馈）调用微信 `security.msgSecCheck` 检测；命中违规（涉政、涉恐、违禁、色情、辱骂等）的内容**直接拦截、拒绝写入**，并提示用户修改（`rides/safe.js`，覆盖点：lifecycle/account/feedback）。
2. **无图片内容**：小程序**未接**图片上传，不存在图片内容面，故无图片机器检测或人工审核之图片场景。
3. **人工复核**：开发者（唯一运营者）对管理员通道收到的高风险内容（含校内身份乱填）进行复核与处置。
4. **行为管理**：成员间的信任问题（性别不实 / 迟到 / 缺勤）通过**成员举报**处理——同局 ≥2 名不同成员联名自动坐实并扣减信用分，不足 2 人转管理员复核；校内身份登记如有乱填，管理员可复核撤销。
5. **用户引导**：注册页提示如实自报；局详情与发局页提示「到点集合、诚信准时、车费线下当面 AA」。

## 四、运营承诺

- 制定并持续更新《使用须知》与规则面板，向用户明示内容与行为规范。
- 对管理员收到的高风险内容与用户举报**及时核查处置**（常规情形 24 小时内响应，重大违规即时报备并处理）。
- 站内提供可达的「反馈与建议」入口，用户的意见与申诉可直达运营者。
- 不主动收集与拼车撮合无关的信息；不将用户内容用于广告、营销或对外共享（详见《用户隐私保护指引》）。

## 五、用户责任

用户承诺所填信息合法合规，不得包含违法、侵权、骚扰、欺诈、泄露他人隐私等不当内容；违反规则将面临内容删除、功能限制乃至账号处置。因线下违约行为引发的纠纷由行为人自行承担，本工具仅作撮合平台、不承担成员线下违约的连带责任。

## 六、投诉举报渠道

- 站内：「我的 → 反馈与建议」；局内成员资料浮层的举报入口。
- 平台侧：微信官方「用户投诉」入口对本小程序提交的投诉，运营者将配合平台核查与处置。
