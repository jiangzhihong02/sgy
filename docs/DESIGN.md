# 深港跨境拼车撮合小程序 — 设计快照（MVP）

> 与领域词汇（CONTEXT.md）与决策记录（docs/adr/）配套的现状快照。改设计时同步更新本文件与对应 ADR。

## 一句话

微信云开发小程序，帮深港跨境通勤者（现阶段 = 往返香港教育大学 EdUHK 的师生）找到**上车时间相同的队伍**组队拼坐香港的士。**纯撮合**：不预约的士、不经手车费、不负责承运，AA 线下进行。作者为爱发电维护，**公益性质、非营利**——如未来开放自愿收款码（覆盖服务器成本）属打赏性质，与"公益"定位一致；不倾向接广告。

## 边界（做 / 不做）

- ✅ 组局撮合、签到、信用分、性别自报 + 头像框着色 + 不实举报、校内身份登记（自报防逃跑威慑）、反馈与建议、管理员代发种子局/复核/撤销
- ❌ 预约/叫车、支付与 AA 收款、**站内聊天**（2026-09-10 下线，ADR-0017：个人主体规避「社交-笔记」UGC 类目；队伍沟通 = 到点集合见人）、常设班次（二期）、正式上架（内测后再说）
- ⚠️ 上下车点：目录预置 7 条；**返校可自定义上车点、离校可自定义下车点**（ADR-0009/0014；返校终点固定教大、离校起点固定教大）

## 拼车局状态机

```
创建(招募中) ──T−60 轮询──▶ (可重复) ──T−30 自由退出截止──▶ T−10 关局（加急局 T−5）
    ├─ ≥2 人 ──▶ 成局(已锁定) ──T──▶ 进行中 ──▶ 已完成（信用分入账）
    └─ <2 人 ──▶ 未成局（自动解散，不计爽约）
发起人可在 T−30 前主动 ──▶ 已取消
```

- **成局门槛 2 人**；人数上限默认 4（发起人可设 2–6，部分车为六人座）。
- **T−60 轮询**：成员未满员（上限 2–6）时全员表态"接受当前人数出发？"，T−45 未回复默认接受；因成员进出可在 T−30 前重复发起。
- **T−30**：成员自由退出 / 发起人自由解散的最后时点。
- **T−10**（加急局 T−5）：停止加入、锁定成局判定。
- **T+10**：停止「我到了」签到；之后到局结束仍未签到的成员，由系统自动按爽约结算扣分。
- 约束：**同一用户可并存多个未出发局**：任意两局出发时间差 ≥1 小时；**同方向（返校×返校 / 离校×离校）需 ≥2 小时**（同向需能先完成一趟往返，见 ADR 并发规则）。

## 信用分（轻量，参数可调）

| 事件 | 分值 |
|---|---|
| 初始 | 100 |
| 爽约（T−30 后退出 / 出发后未签到，经 48h 补签到确认仍没上车或逾期不答） | −20 |
| 举报坐实：迟到 | −10 |
| 举报坐实：缺勤·没来 / 性别不实（性别不实顺带清空性别） | −20 |
| 到点签到且局完成（结算自动） | +1（封顶 120） |

- 信用 <60 → 暂停发起新局 7 天（仍可加入）。
- 举报：同局 ≥2 名不同成员联名自动坐实，不足 2 人转管理员复核（adminPending / resolveReport）。

## 信任与身份

- 注册：填昵称即可（默认昵称随机不同），**无需手机号/实名**——小程序拿不到微信实名明文（ADR-0013）。
- 可选自报性别（微信不提供真实性别）。
- **性别用途**：队伍/成员列表里的头像框着色（蓝男·粉女）便于同车辨认；自报不实可由同车成员举报，坐实后清空性别并扣信用分，屡次/多人坐实则反推为另一性别并锁定（仅管理员可改）。
- **校内身份（防逃跑威慑，ADR-0013）**：仅注册用户可自报「学校（一期固定教大）+ 学号（**s+7 位**格式校验）+ 真实姓名（+可选专业）」，**自报不核验**；同车成员资料只显示「✓ 校内已登记」绿标，**学号/姓名明文不对外**（仅本人与管理员可见）；管理员可撤销乱填登记。
- 不展示微信号、不提供站内聊天；成员按约定时间到上车点的士站集合，凭备注与成员列表互相辨认，车费线下当面结清。

## 页面结构（3 Tab + 子页）

1. **找局**：默认"今天/现在"，可筛方向 + 上车点/下车点 + 还差几人；卡片 = 时间 · 已有几人/上限 · 距发车 · 一键加入。顶栏悬浮"发局"。
2. **行程（我的局）**：进行中 / 历史；局详情 = 时间线 · 成员（可点开资料 / 标记 / 举报 / 再约）· 规则 · 备注（发起人可改）· 人数确认 · 「我到了」· **集合口令**（仅成员可见）。
3. **我的**：昵称/性别注册（自报）、信用分与规则、管理员入口。

- 非 Tab 子页：**发局**（create）、**局详情**（ride）、**管理员后台**（admin）、**反馈与建议**（feedback）、**校内身份**（identity）。

- 局详情可**转发到微信群**（分享卡片：线路 / 时间 / 已有几人 / 还差几人 / 一键加入）——冷启动传播引擎。
- **管理员代发种子局**入口（作者本人专用）：让内测期列表非空。

## 数据与云函数（以 cloudfunctions/SPEC.md 为唯一契约）

一期集合：`users`（档案+信用+校内身份 `schoolId`）、`routes`（线路目录，seed 7 条）、`rides`（拼车局，**members 内嵌** + 派生 `memberOpenids` 供"一人一局/我的局"查询 + `poll` 轮询内嵌）、`reports`（爽约/上报）、`invites`（组队邀请）、`blocks`（不与其乘车标记）、`feedbacks`（用户反馈）。~~`messages`~~（站内聊天下线，2026-09-10，ADR-0017）。

云函数：`routeInit`（建集合+seed）、`rides`（**唯一业务函数**：发/找/加/退/解/签/轮询应答/上报 + 用户档案/信用/复核 + 校内身份 + 反馈，原 `user` 已并入，见 ADR-0012；聊天子域已删）、`rideSweep`（定时推进状态机与结算）。实现与 action 接口见 `cloudfunctions/SPEC.md`。

> 相对早期草图的偏差：成员关系并入 `rides.members`（不再单独 `ride_members` 集合）、轮询并入 `rides.poll`（不再单独 `poll_responses`），均为减少跨集合一致性负担。

## 通知策略

站内为主（红点 + 打开提醒）；订阅消息仅在拿到匹配模板后"尽力"用于最高价值事件（有人加入 / 出发前提醒）。见 ADR-0008。

## 近期规则更新（2026-09，详见 ADR-0010）

- **游客/注册**：未注册可浏览；注册（填昵称，默认昵称随机不同）后才可 发局/加入/邀请/**提交反馈/登记校内身份**。
- **容量**：人数上限默认 4、发起人可设 **2–6**（容纳六人座车）；create 服务端钳制 2–6。
- **校内身份（ADR-0013）**：仅注册可自报「教大 + 学号(s+7 位) + 姓名(+专业)」，**自报不核验**；同车只见「✓ 校内已登记」绿标，明文仅本人/管理员；管理员可撤销乱填。
- **反馈**：我的 → 反馈与建议（仅注册）；管理员后台「反馈建议」栏查看/标已处理。
- **并发**：不再是"一人一未出发局"；可并存多局，但**出发时间相差 ≥1 小时**才可并存（同方向需 ≥2 小时——同向要先完成一趟往返，2026-09-07 修订，见 ADR-0010 第 9 条）；冲突报错带"已加入 / 新建冲突"对比。
- **结算**：上车后 45 分钟关闭进历史（深港单程最慢约 45 分钟，行程结束即结算）。
- **返校自定义上车点（ADR-0014）**：与离校对称——`routeId` 缺省 + `from` 自定义（≤14 字）；找局上车点筛选增加「自定义上车点」项。
- **补签到确认**：结算时未签到**不立即扣分**，挂起；局完成后 48h 内弹窗问"是否上车"（每日至多一次）：上车 → +1，没上/逾期 → −20；谎报靠队友 done 后举报缺勤兜底。
- **举报**：入口在局详情成员浮层；类型 性别不实/迟到/缺勤（去掉"其他"）；同类同一人只能报一次；≥2 名不同成员联名自动坐实扣分，否则转管理员复核。
- **再约**：已完成局"下周同一时刻"再约（自动复用/新建下周局并发邀请）；受邀者在找局顶部看到邀请条。
- **准时提醒（2026-09-10）**：到场前**人数是队友唯一能看到的信号**，故把"退队"从惩罚改写成责任——局详情常驻一条（成员可见）："请按时到达；若赶不上，请在出发前 30 分钟前退出"；并在**打开小程序时**主动弹一次（`departPending`，窗口＝距出发 30–60 分钟，即还来得及免费退出的那一段；每局一次、查询 10 分钟 TTL）；「我到了」的提示改写为"队友看得到你到了"。
- **集合口令（2026-09-10，ADR-0018）**：聊天下线后补上"见着了怎么认"——每局系统生成 **4 位数字口令**，仅同局成员可见。到场后：① 在备注位置附近对一句口令认人；② 成员在微信「面对面建群」输入同号，当场建群，后续协调在微信里。**不用头像**（用户图片＝ADR-0017 那条线）、**不用自定义识别特征**（扩 UGC 面）。「发起人」由此多了**集合召集人**一层含义（只是行为约定、不是权限：他若没到，任何先到成员点「我到了」示意在场即可，无需移交）。成员行另显示「已到 + 时刻」（签到是结构化状态、非用户文本，同局可见），用于扫一眼"谁到了、几点到的"——与口令分工：口令当面认人，时刻远处点名。
- **站内聊天下线（2026-09-10，ADR-0017）**：原「聊天室」Tab、气泡/图片消息、5 秒轮询、每人每局 1 张群二维码、局详情"去聊天室"跳转、48h 保留窗、聊天室公约全部移除。成员不再互发文字/图片（个人主体规避「社交-笔记」UGC 类目）；队伍协调 = 局详情结构化状态（签到/人数确认/备注/成员列表）+ 到点集合见人；AA 线下当面。
- **成员浮层（共用组件）**：`components/member-sheet`——局详情点成员打开资料（昵称/性别/信用/校内绿标 + 标记不与其乘车 + 举报 + 已完成再约）；进行中局只能报性别不实。
- **严谨交互与 AA（2026-09-08）**：「我到了」二次确认（如实签到·互相信任）；发局成功提示「平台建议线下AA，逃单不负责」；局详情常驻「如何AA ›」入口；我的页「如何 AA（线下付款）」教程——面对面（推荐）/ 微信群群收款，图位待作者配图。
- **发局引导**：选完集合时间弹「建议提前约 50 分钟拼车」提示（留出到校+当面AA），可「不再显示」（storage 永久，无重置入口）。
- **首次免责声明（2026-09-08）**：app onLaunch 首次打开弹「使用须知」——公益为爱发电/只提供线上组队/不经手车费不承担承运、AA 自行商量、安全诚信准时付清；单按钮「同意并开始使用」，storage 永久不再弹。
- **关于本工具（2026-09-08）**：我的 → 关于本工具改半屏面板——简介 + 运行版本号（wx.getAccountInfoSync，体验版显示真实版本/工具显示"开发版"）+ 近期更新列表（CHANGELOG，发版时手动加行）。
- **加急局（2026-09-08；发局入口 2026-09-10 修）**：加急**仅适用 15–30 分钟内出发**。**两个方向都能走通**：先选时间——落在这个区间会弹「要按加急局发起吗」；或先勾「加急局」——勾上后时间下限放宽到 15 分钟（此前要求"时间已临近才能勾"，与"未勾加急时下限 31 分钟"互相等待，**加急局永远发不出去**，已修，见 `tests/createGate.spec.js`）。勾选/转加急弹「可能没人响应」提醒、提交时二次确认（发起后不能取消）；关局点放宽到 T−5；凑不齐自动「未成局」不计爽约、不扣发起人分；找局卡片红「加急」标，boardAt 升序天然置顶；冲突校验与普通局同一套。
