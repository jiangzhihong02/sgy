# 双账号真机回归清单（内测）

> 目的：每次改了云函数/页面结构后，用**两个真实微信账号**过一遍核心链路，确认撮合行为没被改坏。
> 账号：作者号（管理员，可在开发者工具里当 1 个号用）+ 至少 1 个真人号；要测 3 人联名举报需 3 个号。
> 已知：重构已把 rides 拆成多文件、rideSweep 委托 `rides.__sweep`、线路下拉改拉 DB。本清单覆盖全部被改面。

## 0. 准备（每次代码变动后）
1. 开发者工具重新编译 → 无误。
2. 若改了云函数：右键对应目录「上传并部署：云端安装依赖」。**顺序：先 rides，再 rideSweep。**
3. 若改了页面/要给别人看：上传代码 → MP 后台设为**体验版** → 每个测试号的微信扫体验版二维码打开。
   - 作者号可以直接在开发者工具里操作（登录即作者 openid）；另一号用真机扫体验版。
4. 每个测试号先「我的」→ 点头像 → **注册昵称**（一个填女、一个填男，便于看头像框蓝/粉）。未注册不能参与。
5. 造一条"已完成局"备用（测 举报/再约/历史 用，不用等 1 小时）：
   云开发控制台 → 云函数 `rides` → 云端测试，入参
   ```json
   { "action": "adminSeedDone", "members": ["<账号A的openid>", "<账号B的openid>", "<账号C(管理员/作者)的openid>"] }
   ```
   （openid 在开发者工具里用云函数查一次：console 打印 `cloud.getWXContext().OPENID`，或看现有代码 `rides/db.js` 的 ADMIN_OPENIDS）→ 记下返回的 `rideId`。

## 4. 成员浮层（回归重点：memberInfo/block/complaint）
- [ ] 详情点队友头像 → 浮层显示 名字/性别/信用分；A 标 B「不与其乘车」→ 可取消。
- [ ] **不可见**：A 标 B 后，B 的找局页**看不到 A 发起的局**（等自动刷新/下拉后）。
- [ ] **入队否决（先到者优先）**：A 已在某局（他人发起的也行）→ B 去加入 → 提示"这一队刚好已满员"（托词），B 进不去、不点名。
- [ ] **反向（后到者自主）**：B 先在某他人局 → A（标记者）后加入 → A 能进但收到提示"这局里有你标过的人"；A 详情顶部横幅持续提示，A 可自行退出。
- [ ] 进行中局：A 报 B「性别填写与真实不符」→ "已提交，待复核"（单人不联名）。
- [ ] **性别分级**：第 0 步已完成局内，① 造出 ≥2 人联名报 B 性别不实 → B 性别被清空、可重填（L1）；② 同一 B 累计 ≥2 次坐实（或单局 ≥3 人同报）→ B 性别被反推锁死，B 的「我的」页性别变为"已核实，不可改"；作者可用 adminSetGender（devtools console）解锁/纠正。
- [ ] 已完成局（第 0 步造的）：A 在 B 浮层可报 迟到/缺勤/性别不符，可「下周同一时刻再约 B」→ B 找局页顶部出现"组队邀请"小条，可 去看看/忽略。

## 9. 编译期约定（2026-09-10，防整页白屏）
- [ ] **客户端 JS 禁用 数组解构 `const [a,b]=…` / 数组展开 `[...x]` / `for…of`**。
  - 原因：客户端**无 npm 产物**（无 `package.json`/`node_modules`/`miniprogram_npm`），而 `project.config.json` 开着 `enhance`（增强编译）。上述语法会被 Babel 编译成 `require('@babel/runtime/helpers/…')` → 模块不存在 → **整页打不开**，报 `module '@babel/runtime/helpers/arrayWithHoles.js' is not defined`，并连带 `Component is not found "wx://not-found"`。
  - 自查（秒级、可自动）：全 `sgy/` 搜上列语法，必须 **0 匹配**。
  - 2026-09-10 已按此修掉 `ride.js` / `create.js` 的 3 处解构（见 commit `2d9b2ef`）。
  - 替代方案（未采用）：关掉 `enhance`（一行配置），但需真机全量回归。
- [ ] 每次开页面若报 `Component is not found "wx://not-found"`，**先怀疑页面模块加载失败**（多为上面的 helper 注入），而不是组件本身（`member-sheet.json` 的 `component: true` 等配置通常是好的）。
